# Citation BIO Gold

Source-of-truth location for engine v2 citation field BIO datasets.

## Subfolders

- `annotations/`: manually reviewed token/span annotations.
- `processed/`: model-ready JSONL exports.
- `reports/`: audit and training status outputs.
- `schemas/`: BIO label schema and validation contracts.

Legacy `ml-service/datasets/citation-bio` paths remain compatibility mirrors
while v1 training scripts are still active.
